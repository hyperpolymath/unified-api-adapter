= Registry state and ownership proof boundary

The executable FFI/API remains pure Zig. `Abi.RegistryState` develops the
authoritative Idris2 transition contract alongside the existing registry and
protocol contracts. Each endpoint is one value containing callback/context
identity, not merely a Boolean registration flag.

The total module proves selected-slot replacement, preservation of the other
slot, busy registration/unregistration refusal, duplicate/absent refusal
framing, exact selected endpoint identity, reentrant call refusal, and endpoint
frame restoration on normal callback return. The existing 1,024-case native
ABI differential campaign remains mandatory. These theorems are development
work until their fresh hosted totality/no-hole check passes.

== Ownership assumptions

The caller owns a live registry exclusively and serializes access. Registered
callback code and context remain live until unregister/destroy, and throughout
any synchronous callback. Input bytes remain readable for the callback's
duration. Foreign code must not mutate registry memory through raw aliases.

An `Invocation` is an ordinary logical snapshot, not an unforgeable runtime
capability and not a linear ownership proof. Busy restoration applies when the
callback returns normally; it establishes neither termination nor safe
non-local jumps, arbitrary foreign corruption, unwinding, or concurrent calls.
