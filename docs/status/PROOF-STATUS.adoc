link:../EXPLAINME.adoc#proof-ledger[proof ledger]. This file holds what the

file the proof gate knows about, and the exceptions to the proof policy.

percentage. All rows are engineering obligations under
`standards/3-practice/PROOF-POLICY.adoc` §1 (Idris2), so they carry §5
status tokens and no Proof Witness Grade.

=== Negative controls

A proof that cannot fail is not evidence. Each mutation below was applied to
a copy of `src/interface/`, and the package was typechecked again. All six
were rejected.

[cols="2,3,2", options="header"]
|===
| Mutation | Change | Rejected by

| Tag collision | `protocolTag REST = 9` -> `7` (Fleet's tag) | `protocolRoundtrip`
| Dropped decode | `protocolFromTag 9 = Just REST` -> `Nothing` | `protocolRoundtrip`
| Implemented protocol refused | `route MCP = Right ViaMcp` -> `Left Unsupported` | `routeImplemented`
| Unimplemented protocol admitted | `route LSP = Left Unsupported` -> `Right ViaRest` | `routeRefuses`
| Status collision | `statusTag Unsupported = 11` -> `2` | `statusRoundtrip`
| Wrong refusal | `route LSP = Left Unsupported` -> `Left InvalidParam` | `routeRefuses`
|===

== Proof files known to the gate

`just proof-check-idris2` (`scripts/check-proofs.sh idris2`) reads
`verification/proofs/idris2/MANIFEST`. It checks only files under
`verification/proofs/idris2/`. The adapter's own modules in
`src/interface/Abi/` are outside its reach and are checked through
`abi.ipkg` as above. Every file below is a template example: the gate

== Exceptions to the proof policy

None. The open decode-soundness row will need one of two routes. The first
is an Idris2 restatement over `Nat`/`Fin 256`, which stays inside §1. The
second is an exhaustive Zig test over all 256 tags, which is `tested-only`
and is recorded as `TESTED` with its bound.
