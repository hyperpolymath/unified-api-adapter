One C ABI for every estate service protocol. A caller links this library and
picks a transport by protocol tag, instead of each service re-rolling its own
HTTP or MCP client.

== What this is

Two things already exist in the estate and are joined here:

* the *protocol taxonomy* from `boj-server` (`Boj.Protocol`): nine wire
  protocols (MCP, LSP, DAP, BSP, NeSy, Agentic, Fleet, gRPC, REST) with an
  Idris2-proven tag encoding (mirrored in Zig and seam-tested in `boj-server`;
  here the Idris2 side exists and the Zig side is still to come);
* the *HTTP connector pool* from `developer-ecosystem/zig-api`
  (`connector.zig`, `uapi_connector_*`), the only one of those protocols with a
  working client today.

In `boj-server` the taxonomy is a column of the cartridge catalogue: it records
which protocols a cartridge exposes, and nothing routes a call by it. This
adapter makes it a dispatch table.

The design rule: *every protocol the ABI names either works or refuses.* A
call on a protocol with no transport returns `UAPI_ERR_UNSUPPORTED`. It is
never silently accepted.

== Layers and plan

[cols="1,2,1"]
|===
| Layer | Content | Source

| Idris2 ABI (`src/interface/Abi/`)
| Protocol tag set and round-trip proofs; open endpoint registry; proof that
  dispatch is total and an unimplemented protocol maps to `UAPI_ERR_UNSUPPORTED`
| `boj-server` `Boj.Protocol`, `zig-api` `ZigApi.ABI.Connector`

| Zig runtime (`src/interface/ffi/`)
| Transport table indexed by protocol tag. REST: the `zig-api` connector,
  moved, not rewritten. MCP: a new JSON-RPC client over HTTP and stdio. The
  other seven protocols are declared and refuse.
| `zig-api` `connector.zig`, `core.zig`; MCP is new

| C header (`src/interface/generated/abi/`)
| Generated from the Idris2 ABI; never edited by hand
| —
|===

Once the adapter is published, `developer-ecosystem/zig-api` and `boj-server`
take it as a pinned dependency instead of carrying their own copies, and
`UNIFIED-ZIG-API-STACK.adoc` points here. Its first new consumer is `svalinn`
(the stapeln edge gateway), which reaches `vordr` over MCP through it.

Proof obligations follow the estate proof policy
(`standards/3-practice/PROOF-POLICY.adoc`): Idris2 for the ABI, Kani for the
`unsafe` and FFI seams of Rust callers.

*Proofs:* 10 proven of 15; 4 open, 1 argued, all named in
link:docs/EXPLAINME.adoc#proof-ledger[the proof ledger]. Proven means proven
for the Idris2 model; the Zig runtime and the C boundary are open rows, and
agreement with `boj-server`'s taxonomy is argued.
